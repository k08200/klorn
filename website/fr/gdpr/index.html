RGPD

Klorn traite le contenu de boîtes mail, ce qui est à peu près ce qu’il y a de plus personnel dans des données professionnelles. Cette page en est la version courte et pratique : quel rôle nous jouons, ce que nous détenons, et comment nous faire donner suite à vos droits. Le détail qui fait foi se trouve dans la politique de confidentialité.

QuestionRéponse
Qui est le responsable du traitement ?Pour un compte individuel, Klorn. Si votre employeur a déployé Klorn pour vous, c’est lui le responsable du traitement et Klorn est le sous-traitant
Ce qui est traitéLes informations du compte, les jetons OAuth Google, les métadonnées et le contenu Gmail, les événements d’agenda, ainsi que les classements et résumés qui en sont dérivés
PourquoiPour fournir le service que vous avez demandé — trier les e-mails, afficher le motif et préparer les actions que vous approuvez
Où c’est stockéBase de données à Séoul (Supabase, ap-northeast-2) ; API à Singapour (Render) ; app web sur le réseau edge de Vercel ; sauvegardes nocturnes chiffrées sur GitHub, qui expirent au bout de 14 jours
Prise de décision automatiséeLe classement dans les files est automatisé. Il n’a aucun effet juridique ni effet significatif similaire : il change seulement la manière plus ou moins insistante dont un message vous parvient, et vous pouvez déplacer n’importe quel message vers une autre file
Entraînement sur vos e-mailsNon. Vos e-mails ne servent pas à entraîner des modèles. Vos corrections ajustent le comportement de votre propre compte
ConservationLes journaux opérationnels sont purgés selon un calendrier fixe — 30, 90 ou 180 jours selon la table. La suppression du compte efface les données du compte

Exercer vos droits

Accès, rectification, effacement, limitation, portabilité et opposition : écrivez à k0820086@gmail.com depuis l’adresse associée au compte. Klorn est un petit produit avec un seul mainteneur ; les demandes sont donc traitées par une personne plutôt que par un portail — comptez une réponse sous quelques jours, pas en quelques minutes.

Vous pouvez révoquer à tout moment l’accès de Klorn à votre boîte mail, sans nous le demander, depuis les autorisations de votre compte Google. Cela coupe immédiatement toute synchronisation future.

Ce que cette page n’est pas. C’est un résumé en langage clair rédigé par le mainteneur, pas un conseil juridique ni un substitut à la politique de confidentialité. En cas de divergence entre les deux, la politique de confidentialité prévaut. Si vous avez besoin d’un accord de traitement des données signé, consultez la page DPA.
