Comptes

Comptes que vous pouvez connecter

La connexion apporte votre premier compte Google. Ajoutez les autres depuis les Réglages.

  • GmailDisponible

    Trié, résumé et consultable.

  • Google AgendaDisponible

    Vos événements à côté de vos e-mails. De nouveaux événements uniquement quand vous le décidez.

  • Naver MailBêta

    Lu et trié avec tout le reste.

  • iCloud MailBêta

    Votre adresse Apple, dans la même liste.

Non pris en charge : les serveurs IMAP autres que Naver Mail et iCloud Mail ne peuvent pas être connectés.

Premier lancement

À quoi vous attendre la première fois

Mac

  1. Ouvrez Klorn.dmg et faites glisser Klorn dans Applications.
  2. Ouvrez Klorn depuis Applications.
  3. Connectez-vous avec votre compte Klorn. Si vous n’en avez pas encore, créez-le dans le navigateur avec votre compte Google.

Windows

  1. Lancez Klorn-windows-setup.exe.
  2. Si SmartScreen indique que Windows a protégé votre ordinateur, choisissez Informations complémentaires, puis Exécuter quand même. L’avertissement apparaît tant que l’app n’est pas signée.
  3. Connectez-vous avec le même compte Klorn que sur le web.

Les notes de version et toutes les builds sont sur GitHub Releases.
