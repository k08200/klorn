ひとつの場所

受信箱はいくつある?
カレンダーは?

仕事の Google、個人のアドレス、iCloud が作ったアドレス、会社が自前で動かしているサーバー。数えると三つから六つになる人が多い — アプリも通知も、何が緊急かの基準もそれぞれ別だ。Klorn はそのすべてが届く一箇所です。どのメールも同じ五つのレーンに、同じように理由が付いて入り、何かが会議だと名乗る前にカレンダーを確認します。

今つながるもの

Gmail・Google Workspace個人も業務も OAuth で — パスワードは保存しません。
Naver メールIMAP で接続し、同じ五つのレーンに分類されます。
Google カレンダー読み取り・作成・移動・キャンセル。会議メールは衝突をカレンダーと照合します。

マージ済み・まだ無効

Apple メール (iCloud)アプリ用パスワードと IMAP — Apple はメール API を公開していません。
Microsoft 365・OutlookGraph 経由でメールとカレンダー。当方の Azure 登録が未了です。
任意の IMAP サーバーFastmail、Daum、社内サーバー — 接続前にホストを解決しアドレスを固定します。
CalDAV カレンダー標準ひとつで iCloud・Naver・自社運用のカレンダーの多くが開きます。

右の列は main にマージ済みでテスト中です。本番では意図的に無効にしています。Klorn の Gmail スコープが Google の OAuth 検証審査中であり(CASA Tier 2 評価完了、検証書を 2026-10-02 に提出)、審査中に監査を受けた範囲を変更しません。審査が終わってから有効にします — そのため、このページには今日つなげられるものだけを載せています。 計画の全文はリポジトリに →

01 · 何があなたに届くかを誰が決めるか

Klornが決めます — 1通につき1つの判定を5つのレーンへ。送信・削除・転送はいまもあなたを待ち、そのたびにレシートを発行します。

01 · 何があなたに届くかを誰が決めるか

FyxerとSuperhumanは、すでに開いたメールを速く片づけさせます。何を開く価値があったかの判断は、1日中、1通ごとにあなたに残ります。

02 · なぜそう判定したか

理由が全行に書かれています。行を動かせばその修正が学習信号になり、同じ修正が2回そろえばその送信者は決定論的になります。

02 · なぜそう判定したか

Fyxerは理由を出しません。SaneBoxは、届いたフォルダから推測させます。どちらの判定も、あとから監査できません。

03 · 何を主張するか

再実行できる数値 — 評価セットはすべてリポジトリにあります（pnpm eval:judge、pnpm eval:real）。再現しなくなった数値は、このページから取り下げました。

03 · 何を主張するか

「AI搭載」。公開された評価セットも、コールド／ウォームの区別も、自分で数値を確かめる手段もありません。

04 · 抜けたくなったら

無改変のAGPL-3.0。追加条項なし、商用利用の制限なし、5人条項なし。自分の鍵でセルフホストしても、フォークして去っても構いません。

04 · 抜けたくなったら

Inbox ZeroはAGPLのうしろにADDITIONAL TERMSを足しています — 商用の収益化を制限し、5人以上の組織はライセンス取得が必要です。GitHubはそのファイルをNOASSERTIONと判定します。残り3つはクローズドです。

vs Fyxerユーザー1人あたり月$30で、あなたの文体の下書き。クローズド、クラウド専用、理由の提示なし。 vs Superhuman1通あたりの時間を半分にするのは、あなたが選んでいない数への掛け算です。 vs Inbox Zero両方のLICENSEを2つのタブで開いてください。片方はAGPLで、そこで終わります。 vs SaneBox本文を一切読まない — より強いプライバシーの一文と、その代償。

    よくある質問

    実際に
    届く質問。

    私の承認なしに何かを送信することはありますか？

    ありません。送信、削除、転送は必ず明示的な承認を待ち、実際に出た内容のハッシュを固定したレシートを それぞれ記録します。

    私のメールは実際どこへ行くのですか？

    分類器へ渡り、戻ってくるだけです。OAuthトークンは保存時に暗号化されており、全体がAGPLv3なので それに触れるコードを自分で読めます — 自分で動かすこともできます.

    誤った場所に仕分けされたらどうなりますか？

    動かしてください。すべてのメールにはそこへ入った理由が表示され、その修正から分類器が学習します — コールドスタートと、あなたの送信者をすでに知っている分類器の差です。

    Windows版はいつですか？

    未署名ベータとして出荷済みです — コード署名が済むまではSmartScreenが一度警告します。ウェブアプリは 同じアカウントとティアで、どのブラウザからでも引き続き利用できます。

    AIが請求を膨らませることはありますか？

    ありません。Klornは1日あたりの支出に自分で上限を設け、使いすぎるくらいなら停止します — 暴走した ループにコストはかかりません。この上限があるから、仕分けは無料のままです。

    サインインするとGoogleが警告を出すのはなぜですか？

    メールを読むにはGoogleの制限付きスコープが必要で、アプリが確認済みになるにはセキュリティレビューを 通す必要があります。それが通るまでは未確認アプリの画面が一度表示され、ベータは先着100アカウントに 限定されます。
