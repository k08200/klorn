GDPR

Klorn 处理邮箱内容，这几乎是最私人的工作数据了。本页是简短实用的版本：我们扮演什么角色、持有哪些数据，以及如何让我们落实你的权利。具有约束力的细节见隐私政策。

问题回答
谁是控制者？对于个人账户，是 Klorn。如果是你的雇主为你部署了 Klorn，则雇主是控制者，Klorn 是处理者
处理哪些数据账户信息、Google OAuth 令牌、Gmail 元数据与内容、日历日程，以及由此得出的分类和摘要
为什么处理为了提供你所要求的服务——分拣邮件、显示理由，以及准备由你批准的操作
存储在哪里数据库位于首尔（Supabase，ap-northeast-2）；API 位于新加坡（Render）；网页应用运行在 Vercel 的边缘网络上；每晚的加密备份存放在 GitHub 上，14 天后过期
自动化决策把邮件分到各个分类是自动完成的。它不产生法律效力或类似的重大影响：它只改变一封邮件以多显眼的方式送达你，而且你可以把任何邮件移到另一个分类
用你的邮件训练模型不会。你的邮件不会用于训练模型。你做的纠正只用于调整你自己账户的行为
保留期限运营日志按固定时间表清理——视数据表不同为 30、90 或 180 天。删除账户会移除账户数据

行使你的权利

访问、更正、删除、限制处理、可携带和反对：请用账户所用的邮箱地址发邮件至 k0820086@gmail.com。Klorn 是只有一名维护者的小产品，所以请求由人工处理，而不是通过自助门户——预计几天内回复，而不是几分钟。

你可以随时在你的 Google 账号权限页面撤销 Klorn 对你邮箱的访问，无需征得我们同意。这会立即切断之后的同步。

本页不是什么。这是维护者撰写的通俗摘要，不是法律意见，也不能替代隐私政策。两者有出入时，以隐私政策为准。如果你需要签署数据处理协议，请参阅 DPA。
